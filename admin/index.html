Se încarcă…

Backend-ul nu rulează aici

Panoul de administrare funcționează doar împreună cu serverul Afyze. Pe GitHub Pages site-ul e static, așa că panoul nu se poate conecta.

  1. Deschide un terminal în folderul server al proiectului.
  2. Rulează npm install, apoi npm run setup (o singură dată).
  3. Pornește serverul cu npm start.
  4. Deschide http://localhost:3000/admin/.

Creează contul de administrator

Din motive de securitate, contul se creează doar de pe computerul pe care rulează serverul. În folderul server, rulează:

npm run setup

Apoi reîncarcă această pagină.
